MAIN PROJECT

Jarvis

What is Tanmay Malaviya building?

Jarvis is Tanmay Malaviya's personal assistant project. It is being developed as a multi-purpose assistant designed to understand commands, provide useful information, assist with tasks and gradually gain more capabilities.


The project combines AI, voice interaction, memory, automation, software assistance and future Android integrations into one continuously evolving system.
